Single Click Stream

Single Click Stream is a small personal desktop app for Windows. With one click, it starts a YouTube live stream of the user's own screen and computer sound, and gives a link to share the stream.

The app uses the YouTube Data API to:

  • create a live broadcast and a live stream on the user's own YouTube channel,
  • change the title and the privacy (public, unlisted, private) of the user's broadcasts,
  • stop and delete the user's broadcasts.

The app runs only on the user's own computer. It has no server and no other users.
