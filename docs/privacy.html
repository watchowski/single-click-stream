Privacy Policy

App: Single Click Stream
Last updated: November 26, 2026

What data the app uses

The app asks for access to the user's YouTube account (scope https://www.googleapis.com/auth/youtube). It uses this access only to create, change, stop, list and delete live broadcasts on the user's own channel, when the user asks for it in the app.

Where the data is kept

The sign-in token is saved only in a file on the user's own computer. The app has no server. The app does not send any data to the developer or to any third party. The only service the app talks to is Google / YouTube.

The screen and sound of the computer are sent only to YouTube, and only while the user streams.

What the app does not do

  • It does not sell, share or transfer user data.
  • It does not use user data for advertising.
  • It does not keep analytics or tracking data.

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

How to remove access

To remove the app's access, go to https://myaccount.google.com/permissions and remove "Single Click Stream". Delete the file token.json in the app folder.
